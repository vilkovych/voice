# Voice

Диктовка для macOS. Двічі натискаєш правий Shift, говориш, натискаєш Shift ще раз, і текст з'являється там, де стоїть курсор: у браузері, терміналі, месенджері, будь-де. Програма живе у смужці меню, пам'ятає всі диктовки і не губить запис, навіть якщо пропав інтернет.

## Що потрібно

- Mac з macOS 13 або новішою (Apple Silicon або Intel).
- Інструменти розробника Apple. Якщо їх немає, постав командою `xcode-select --install` або встанови Xcode.
- Ключ AssemblyAI: голос розпізнається через їхній сервіс. Ключ видають на assemblyai.com у розділі API Keys.

## Встановлення

```
git clone https://github.com/vilkovych/voice.git
cd voice
./install.sh
```

Скрипт збирає програму, ставить її в `~/Applications/Voice.app` і запускає. Першого разу він:

- попросить вставити ключ AssemblyAI (ключ зберігається у `~/Library/Application Support/Voice/keys.txt`);
- створить локальний сертифікат для підпису, щоб дозволи macOS не злітали після кожного перезбирання.

## Дозволи

На першому запуску macOS спитає два дозволи:

- **Мікрофон.** Дозволь.
- **Універсальний доступ** (System Settings → Privacy & Security → Accessibility). Увімкни Voice. Без цього програма не чує клавіш і не може вставити текст.

Якщо чогось бракує, панель під значком Voice покаже, чого саме, і відкриє потрібне місце в налаштуваннях.

## Як користуватися

| Що | Як |
|---|---|
| почати диктовку | двічі правий Shift |
| закінчити, текст вставиться під курсор | ще раз правий Shift |
| скасувати запис | Esc |
| вставити останню диктовку | ⌃⌥V |
| скопіювати останню диктовку | ⌃⌥C |
| історія всіх диктовок | ⌃⌥H |

Клік по значку в смужці меню відкриває панель з останніми диктовками. Там же налаштування (шестірня):

- клавіша запуску: правий Shift, правий Option або будь-який Option;
- вигляд смужки запису: «Спектр», «Стрічка» або «Хвиля»;
- звуки.

Правий клік по значку відкриває коротке меню.

Якщо інтернет пропав, запис не губиться: Voice покаже «Не вдалося» і сам розпізнає його ще раз, коли зв'язок повернеться.

Мова розпізнавання — українська (`language_code` у `AssemblyAI.swift`).

## Оновити, прибрати, автозапуск

- **Оновити:** `git pull && ./install.sh`.
- **Прибрати програму:** `./install.sh --remove`. Історія лишається в `~/Library/Application Support/Voice`.
- **Запускати разом із Маком:** System Settings → General → Login Items, додай Voice з `~/Applications`.

## Де що лежить

- `~/Library/Application Support/Voice/` — ключі, історія, налаштування і звук диктовок.
  - У `keys.txt` можна записати кілька ключів, по одному в рядку. Якщо ключ не приймається, Voice бере наступний.
  - Звук старших за 14 днів диктовок видаляється, текст лишається.
- `~/Library/Logs/Voice.log` — журнал. Тексту диктовок і ключів у ньому немає.

## Якщо щось не так

- **Смужка пише «Немає ключів»:** файлу `keys.txt` немає або він порожній. Допиши ключ і диктуй знову, перезапускати не треба.
- **«Ключі не працюють»:** AssemblyAI відхилив ключ. Перевір ключ або баланс.
- **Клавіші не реагують:** перевір Універсальний доступ. Якщо Voice там увімкнено, а клавіші все одно не працюють, вимкни й увімкни його в цьому списку.
- **Текст вставляється двічі:** правий Shift слухає ще якась програма, наприклад Wispr Flow. Вимкни її або зміни клавішу в налаштуваннях Voice.
- **Збірка не проходить:** перевір `xcode-select --install`. Команда `VOICE_ADHOC=1 ./install.sh` підписує програму без окремого сертифіката, але тоді дозволи доведеться давати заново після кожного перезбирання.
